The core idea

There are two layers. First, §4 compares sheaf-theoretic Hom groups on a biprojective scheme with a suitably truncated module Hom. Second, §5 specializes this calculation to \(M=N=R\) for the graph of a morphism \(f:Y\to X\).

\[ C=\operatorname{Hom}_R(R_{\ge r},R)_{(0,\ge 0)}. \]

The first grading records the source direction and the second records the target direction. In the Stein specialization, the degree-\((0,\ge0)\) part reconstructs the intermediate \(Z\), giving \(Y\to Z\to X\).

Reading convention. A bound computed from the prescribed free-resolution formula is certified. A supplied or stabilized bound is useful evidence, but is explicitly marked non-certified.

Results from the paper used in these computations

This page uses the following statements from Yasuda, arXiv:2603.13703v2. They are summarized only to explain what is being computed; proofs are in the paper. The first item is the bigraded extension of the truncation method in Smith's 2000 paper.

§4 · Proposition 4.2

Large bidegrees turn module Hom into sheaf Hom

For finitely generated bigraded \(R\)-modules \(M,N\), Yasuda gives an explicit pair \(\mathbf e_0\), read from the shifts in resolutions of \(M\) and \(N\), such that for every \(\mathbf e\geq\mathbf e_0\),

\[\bigoplus_{\mathbf v\geq\mathbf e}\operatorname{Hom}_X(\widetilde M,\widetilde N(\mathbf v))\;\cong\;\operatorname{Hom}_R(M,N)_{\geq\mathbf e}.\]

Thus a finite free-resolution calculation controls all sufficiently positive twists at once. This is the bigraded analogue of the truncation principle used in Smith, Proposition 2.5.

§4 · Corollary 4.3

A convenient truncation form

If \(\mathbf r\) is at least the stated shift bound for \(N\), then truncating the source module gives

\[\bigoplus_{\mathbf v\in\mathbb N^2}\operatorname{Hom}_X(\widetilde M,\widetilde N(\mathbf v))\;\cong\;\operatorname{Hom}_R(M_{\geq\mathbf r},N)_{\geq\mathbf 0}.\]

This is the formula that makes a finite M2 computation possible. The current Stein functions implement its special case \(M=N=R\).

§5 · Lemma 5.1

The coordinate ring determines the finite morphism

Let \(C=\bigoplus_{v\geq0}H^0(X,(f_*\mathcal O_Y)(v))\). The natural graded map from the coordinate ring \(A\) of \(X\) to \(C\) induces the finite map \(g:Z\to X\) in the Stein factorization.

§5 · Lemma 5.2

Recover the algebra inside one localization

For nonzero bihomogeneous \(\gamma\in R_{\geq\mathbf r}\), evaluation gives an injective, degree-preserving ring map

\[\operatorname{Hom}_R(R_{\geq\mathbf r},R)_{0,\geq0}\longrightarrow R_\gamma,\qquad \psi\longmapsto\frac{\psi(\gamma)}{\gamma}.\]

Taking a kernel after adjoining variables for these evaluated generators produces explicit equations for \(C\).

§5 · Lemma 5.3 and Proposition 5.4

Recover the connected-fiber map and the full factorization

Pull the graph of \(f\) back to \(Y\times Z\). Any reduced irreducible component that maps isomorphically to \(Y\) is the graph of the connected-fiber morphism \(h:Y\to Z\) (Lemma 5.3). Proposition 5.4 states that this procedure gives an algorithm for the Stein factorization of a surjective graph morphism.

Notation in Chapter 4 and in the code

The paper's Chapter 4 notation is compressed. The following dictionary explains what is represented by the variables in this implementation.

\(I_{\Gamma}\)The bihomogeneous ideal of the graph.igraph or graphIdeal
\(R=S/I_{\Gamma}\)The bigraded coordinate ring of the graph.rr := ambient/igraph
\(d=(d_1,d_2)\)The two dimension parameters used in the shift bound.d1,d2; each is one less than the number of variables in its block.
\(c=(c_1,c_2)\)The sum of the variable weights in each grading block.c1,c2
\(\mathbf a_{i,j}(R)\)The pair of maximum shift components read from selected homological degrees.aPair(ff,i,j)
\(\overline{\mathbf a}(R)\)The componentwise maximum of the relevant \(\mathbf a\)-pairs.pairMax({...}), stored temporarily as bb
\(\mathbf r=(r_1,r_2)\)The lower corner of the orthant truncation \(R_{\ge\mathbf r}\).bound, returned by bigradedTruncationBound
\(R_{\ge\mathbf r}\)The direct sum of pieces whose two degrees are at least those of \(\mathbf r\).truncation := truncate(bound,rr^1)
\(\mathbf e_1,\mathbf e_2\)The standard grading directions, implicit in the two degree components.Lists such as {1,0} and {0,1}

Thus, the code is not introducing a new “bound” notation: bigradedTruncationBound is the implementation name for the paper's componentwise shift estimate, while bound is the actual pair \(\mathbf r\) passed to truncate.

Independent bigraded global Hom calculations

These small calculations concern §4 directly, before any Stein factorization is introduced. Put \(S=\mathbb Q[y_0,y_1,x_0,x_1]\) with \(\deg y_i=(1,0)\) and \(\deg x_i=(0,1)\), so that \(\operatorname{biProj}S=\mathbb P^1\times\mathbb P^1\). The function bigradedGlobalHomData now packages the certified bound from Proposition 4.2. The elementary displays below use M2's truncate and Hom directly, so the underlying calculation remains visible.

Example GH1 · structure sheaf

\(\operatorname{Hom}(\mathcal O,\mathcal O)\)

Taking \(M=N=S\), the module Hom has one generator in bidegree \((0,0)\). This is the identity map of the structure sheaf. It is the simplest check that the M2 construction has the expected normalization.

o = 1
Example GH2 · a line bundle

\(\operatorname{Hom}(\mathcal O(-1,-1),\mathcal O)\)

Example GH3 · the diagonal

Endomorphisms of the diagonal \(\mathbb P^1\)

Let \(R=S/(y_0x_1-y_1x_0)\), the bihomogeneous coordinate ring of the diagonal \(\Delta\subset\mathbb P^1\times\mathbb P^1\). The Hom module of the structure sheaf of \(\Delta\) has one degree-\((0,0)\) generator. Its components have dimensions \(1,3,4\) in bidegrees \((0,0),(1,1),(2,1)\), agreeing with \(H^0(\mathbb P^1,\mathcal O(a+b))\).

One calculation, step by step

1 · input

Graph ring

Give a bigraded polynomial ring \(S\) and a graph ideal \(I_\Gamma\), then set \(R=S/I_\Gamma\).

2 · bound

Truncate

Compute \(r\) from shifts, or supply an experimental \(r\), and form \(R_{\ge r}\).

3 · Hom

Select degrees

Compute \(\operatorname{Hom}_R(R_{\ge r},R)\) and retain generators of degree \((0,\ge0)\).

4 · output

Recover \(Z\)

Evaluate at \(\gamma\), take a kernel, and compute the graph closure of the Stein morphism.

Functions, with their actual M2 definitions

Each card gives the mathematical role and places the corresponding M2 definition directly underneath it. When served over the web, the page reads the current source file; when opened directly from disk, it uses the source snapshot bundled into this page. Click a function name to reveal its code.

Shift-data helpers: componentMax, componentMin, shiftCoordinateMax, aPair, pairMax, sourceLowerShift, isSteinDegree

Role: these small functions extract maximum and minimum shift coordinates from a resolution. The minimum degree-zero shift of \(M\) is the extra term required in Proposition 4.2; isSteinDegree selects the degree-\((0,\ge0)\) generators used for the Stein strand.

Paper: Definition 4.1 and the shift bookkeeping used by the truncation estimate.

bigradedTruncationBound

Input: a bigraded free resolution and block dimensions and weight sums.

Output: a pair \(\{r_1,r_2\}\).

Paper: the shift calculation behind Corollary 4.3.

bigradedGlobalHomBound / bigradedGlobalHomData

Input: bigraded \(R\)-modules \(M,N\), together with an ambient-\(S\) presentation of \(N\), and the two block dimensions and weight sums.

Output: the certified Proposition 4.2 bound, \(M_{\geq r}\), and \(\operatorname{Hom}_R(M_{\geq r},N)_{\geq0}\).

Paper: Proposition 4.2 and Corollary 4.3. The separate ambient presentation is required because the bound uses the \(S\)-free resolution of \(N\).

steinHomData

Input: \(S\), the graph ideal, and degree parameters.

Output: a HashTable containing \(R\), the resolution, bound, truncated module, and selected generators.

Paper: the §5.1 Hom-module construction.

steinHomDataAtBound

Input: \(S\), graph ideal, and supplied \(r\).

Output: the same kind of data with certifiedBound => false.

Use: heavy examples where deriving the bound is the bottleneck.

evaluateSteinGenerators

Input: Hom data and an index selecting \(\gamma\in R_{\ge r}\).

Output: the list \(\psi_i(\gamma)\).

Paper: the evaluation map in Lemma 5.2.

steinCoordinateAlgebra

Input: Hom data, \(\gamma\), and images of target generators.

Output: a presentation of \(C\), its defining ideal, and the finite \(A\)-module strand.

Paper: \(\psi\mapsto\psi(\gamma)/\gamma\) and coordinate-algebra reconstruction.

directSteinGraph

Input: Hom data and coordinate-algebra data.

Output: a graph ideal in a joint source–Stein polynomial ring.

Paper: graph closure through localization.

steinFingerprint / steinDataByStabilization

Output: dimension, Hilbert values, generator degrees, and a stabilization history.

Caution: finite agreement is not a proof of the bound.

Graph certificates: certifiedHomogeneousGraph, selectCertifiedGraphComponent, ringMapsAreInverse, certifyChartwiseProjectionIsomorphism

Input: explicit homogeneous forms or affine chart maps.

Example: the quadratic map of \(\mathbb{P}^1\)

For \([s:t]\mapsto[s^2:t^2]\), the graph relation is \(y_0^2x_1-y_1^2x_0\). The code asks for Hom data and reconstructs the intermediate coordinate ring.

The three graph morphisms in this example

Write \(\Gamma_f\subset\mathbb{P}^1_y\times\mathbb{P}^1_x\), \(\Gamma_h\subset\mathbb{P}^1_y\times Z_U\), and \(\Gamma_g\subset Z_U\times\mathbb{P}^1_x\). In the coordinate order \(U=(U_{00},U_{01},U_{11})\), their defining equations are:

\[ \begin{aligned} I_{\Gamma_f}&=(y_0^2x_1-y_1^2x_0),\\ I_Z&=(U_{01}^2-U_{00}U_{11}),\\ I_{\Gamma_h}&=(U_{01}^2-U_{00}U_{11},\;y_1U_{00}-y_0U_{01},\;y_1U_{01}-y_0U_{11}),\\ I_{\Gamma_g}&=(U_{01}^2-U_{00}U_{11},\;U_{00}x_1-U_{11}x_0). \end{aligned} \]

Thus the displayed graph equations make the equality \(f=g\circ h\) concrete: the source coordinates satisfy \(x_0:y_0^2=x_1:y_1^2\), \(h\) is the quadratic Veronese map, and \(g\) forgets the middle coordinate.

Show the complete M2 calculation for this example

More mathematical examples

Mori fiber space

\(\mathbb{P}^1\times\mathbb{P}^2\to\mathbb{P}^2\)

Here the map is a projection followed by the coordinatewise square map on \(\mathbb{P}^2\). The projection has connected \(\mathbb{P}^1\)-fibers, while the square map has degree four over a general target point. The Stein intermediate keeps the \(\mathbb{P}^2\) and removes the disconnected finite part.

\[\mathbb{P}^1\times\mathbb{P}^2\longrightarrow \mathbb{P}^2\longrightarrow \mathbb{P}^2.\]

The test obtains \(\dim C=3\), \(H_C(1)=6\), \(H_C(2)=15\), and four reduced fiber components, each a copy of \(\mathbb{P}^1\).

Divisorial contraction

\(\operatorname{Bl}_L(\mathbb{P}^3)\to\mathbb{P}^3\)

The source is the blow-up of a line \(L\), followed by the coordinatewise square map on \(\mathbb{P}^3\). The connected-fiber part is the blow-down; the finite part is the degree-eight square map on a general fiber.

The computed Stein ring has \(H_C(1)=10\) and \(H_C(2)=35\), the values expected for the second Veronese ring of \(\mathbb{P}^3\). The exceptional divisor has degree two, matching a Segre quadric \(\mathbb{P}^1\times\mathbb{P}^1\).

Defining equations for the computed Stein varieties and maps

The raw ring returned by Macaulay2 can contain automatically named variables, and in the \(\mathbb{P}^3\) examples it contains one redundant algebra generator. The presentations below are therefore the natural minimal presentations of the same Stein variety \(Z\). They make the defining equations and the two morphisms visible without printing a long, less informative elimination ideal.

Finite maps of P1

The conic and the twisted cubic

For \([s:t]\mapsto[s^2:t^2]\), use coordinates \([U_{00}:U_{01}:U_{11}]=[s^2:st:t^2]\). Then

\[ Z=V(U_{01}^2-U_{00}U_{11})\subset\mathbb{P}^2,\qquad h([s:t])=[s^2:st:t^2],\qquad g([U_{00}:U_{01}:U_{11}])=[U_{00}:U_{11}]. \]

For \([s:t]\mapsto[s^3:t^3]\), use \([U_0:U_1:U_2:U_3]=[t^3:st^2:s^2t:s^3]\). The intermediate is the twisted cubic:

\[ I_Z=(U_1^2-U_0U_2,\;U_1U_2-U_0U_3,\;U_2^2-U_1U_3), \qquad g([U_0:U_1:U_2:U_3])=[U_3:U_0]. \]
Mori fiber space

The quadratic Veronese surface

For \(\mathbb{P}^1\times\mathbb{P}^2\to\mathbb{P}^2\), write the intermediate in coordinates

\[ [U_{00}:U_{01}:U_{02}:U_{11}:U_{12}:U_{22}] =[x_0^2:x_0x_1:x_0x_2:x_1^2:x_1x_2:x_2^2]. \]

Then \(Z\cong v_2(\mathbb{P}^2)\subset\mathbb{P}^5\) is the rank-one locus of the symmetric matrix

\[ M_2=\begin{pmatrix} U_{00}&U_{01}&U_{02}\\ U_{01}&U_{11}&U_{12}\\ U_{02}&U_{12}&U_{22} \end{pmatrix}, \qquad I_Z=I_2(M_2). \]

Explicitly, the six quadrics are

\[ \begin{aligned} I_Z=(&U_{01}^2-U_{00}U_{11},\ U_{02}^2-U_{00}U_{22},\ U_{12}^2-U_{11}U_{22},\\ &U_{01}U_{02}-U_{00}U_{12},\ U_{01}U_{12}-U_{11}U_{02},\ U_{02}U_{12}-U_{22}U_{01}). \end{aligned} \]

The factorization maps are

\[ h([s:t],[x_0:x_1:x_2])=[x_0^2:x_0x_1:x_0x_2:x_1^2:x_1x_2:x_2^2], \qquad g([U_{ij}])=[U_{00}:U_{11}:U_{22}]. \]
Both blow-up examples

The quadratic Veronese threefold

For both \(\operatorname{Bl}_L(\mathbb{P}^3)\) and the blow-up of the twisted cubic, the expected Stein intermediate is \(v_2(\mathbb{P}^3)\subset\mathbb{P}^9\). In natural coordinates \(U_{ij}=x_ix_j\), it is defined compactly by

\[ M_3=\begin{pmatrix} U_{00}&U_{01}&U_{02}&U_{03}\\ U_{01}&U_{11}&U_{12}&U_{13}\\ U_{02}&U_{12}&U_{22}&U_{23}\\ U_{03}&U_{13}&U_{23}&U_{33} \end{pmatrix}, \qquad I_Z=I_2(M_3). \]

The ideal has many quadratic generators. To show its scale, here is a representative initial portion; the compact formula \(I_2(M_3)\) above is the complete definition.

\[ \begin{aligned} I_Z\supset(&U_{01}^2-U_{00}U_{11},\ U_{02}^2-U_{00}U_{22},\ U_{03}^2-U_{00}U_{33},\\ &U_{12}^2-U_{11}U_{22},\ U_{13}^2-U_{11}U_{33},\ U_{23}^2-U_{22}U_{33},\\ &U_{01}U_{02}-U_{00}U_{12},\ U_{01}U_{03}-U_{00}U_{13},\\ &U_{02}U_{03}-U_{00}U_{23},\ U_{01}U_{12}-U_{11}U_{02},\ \ldots). \end{aligned} \]

The connected-fiber map is the blow-down followed by the quadratic Veronese embedding:

\[ h(\widetilde{x})=[x_0^2:x_0x_1:\cdots:x_3^2], \qquad g([U_{ij}])=[U_{00}:U_{11}:U_{22}:U_{33}]. \]

For the line blow-up, the test verifies the matching Hilbert values \(H_C(1)=10\), \(H_C(2)=35\), primality, the exceptional quadric, and the eight-point general fiber. For the twisted-cubic blow-up, it verifies the same Hilbert values at the supplied bound \((2,0)\). The latter has not yet had its graph fully minimized and automated.

Why not print every generator of every raw ideal? The line-blow-up graph has 26 generators and the twisted-cubic composite graph has 70. Printing all of them obscures the geometry. The page instead displays the equations that define the source, the parametrization used to build the graph, the standard defining ideal of the computed \(Z\), and the numerical checks that identify it.

What is certified, and what is experimental?

  • steinHomData computes its truncation bound from a bounded free resolution.
  • steinHomDataAtBound accepts a supplied bound and marks it non-certified.
  • steinDataByStabilization compares finite data; stabilization is evidence, not proof.
  • Some Hom-module generators can be redundant as algebra generators. This remains the obstacle in the twisted-cubic blow-up example.

The calculations are meant to be rerun. Download the project directory, not only the HTML page: the implementation file and the example files are intended to live together.

Option A: run locally with Macaulay2

  1. Install Macaulay2 1.24.11 or a later compatible version.
  2. Download or clone this project directory, preserving SteinFactorization.m2, tests/, and run-tests.sh.
  3. In a terminal, change into the project directory and run the standard tests.
Show local commands
cd "/path/to/SteinFactorizationM2"

# Run the standard regression suite.
./run-tests.sh

# Or run one example only.
M2 --no-readline --stop -q tests/basic.m2

# Start an interactive session in the project directory.
M2
i1 : load "SteinFactorization.m2";

The standard suite runs the basic examples, the Mori fiber-space example, and the line-blow-up example. The twisted-cubic benchmark is slower and is run separately with M2 --no-readline --stop -q tests/blowup-twisted-cubic.m2.

Option B: use Macaulay2Web without a local installation

Macaulay2Web provides a browser-based Macaulay2 editor. It has a Start button, an Editor, and file-upload support. Use a modern browser; its own documentation notes that Safari is not supported.

  1. Open Macaulay2Web and start a new editor session.
  2. On this page, open Show the full source file in the Functions section and use Copy.
  3. Paste that source into the editor and run it. This defines the functions.
  4. Copy one example block below, paste it after the source, and run it.
Show a self-contained first experiment for Macaulay2Web
-- First paste the whole SteinFactorization.m2 source from this web page.
-- Then paste and run the following example.

S = QQ[y0,y1,x0,x1,
    Degrees=>{{1,0},{1,0},{0,1},{0,1}}];

igraph = ideal(y0^2*x1-y1^2*x0);
data = steinHomData(S,igraph,1,1,2,2);
cData = steinCoordinateAlgebra(data,0,{x0,x1});
gData = directSteinGraph(data,cData);

data#"bound"
cData#"definingIdeal"
isPrime(gData#"graphIdeal")
Important. The browser editor does not automatically know this project's functions. Paste or upload SteinFactorization.m2 first, then run an example. The code cells in this page are designed to be copied in that order.
